# Comprendre les prix

Estimations communautaires et références de gros apportent des informations différentes. Voici comment les lire.

Les estimations utilisent les signalements de la région choisie, si les données sont suffisantes. Elles varient selon la qualité, le lieu et les contributions.

Les bulletins Casa Prestations concernent le marché de gros de Casablanca. Ce ne sont pas des prix de détail garantis dans votre région.

Repérez les DH/kg ou les DH par œuf, selon le produit. Lisez aussi la source et la date à côté du montant.

Un manque de données clairement indiqué vaut mieux qu’un prix inventé. Utilisez ces informations pour éclairer vos courses.
