# Social media graphics

[October 2026 SOUK-SCAN campaign](2026-10/) includes six square post designs and
three five-slide carousel topics, each fully localized into Arabic, French
and English: 63 graphics in total.

[Download the posting pack](2026-10/souk-scan-social-media.zip), or browse the
[English](2026-10/posts/en/), [French](2026-10/posts/fr/) and
[Arabic](2026-10/posts/ar/) square posts. Carousel folders include numbered
slides and suggested captions. Editable sources and validation reports are
retained with the campaign.
