# Google Play store graphics

[Version 1.1.0 promotional assets](v1.1.0/) contain the final Arabic, French and
English graphics, raw captures, editable layouts and validation reports.

[Download the complete upload pack](v1.1.0/souk-scan-play-store.zip).

Each language has four 1080 × 1920 phone screenshots and one 1024 × 500 feature
graphic. The shared app icon is 512 × 512. The first screenshot shows the product
page and price-entry form. The final screenshots use realistic, straight Android
phone mockups and keep the three approved feature graphics unchanged.

These files are store-listing materials. Keeping them under `docs/` excludes them
from the public website build. Saving them here does not submit a Play listing.
